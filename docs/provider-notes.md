## 3. 鉴权与本地配置

### 3.1 文档规定

- Base URL：`https://fuyao.aicubes.cn`。
- 标准 `/api/**` 数据请求需要请求头 `X-api-key`。
- 请求头值为在站点签发的 API Key，不是个人 ChatGPT Key，也不是股票代码。
- 使用同花顺账号登录站点，再到 <https://fuyao.aicubes.cn/admin> 创建和管理 API Key。
- 缺失或无效 Key：业务 `code=2001`。
- 没有对应 capability 权限：业务 `code=2003`。
- 标准 REST 不以浏览器登录 Cookie 代替此请求头；Market Dumps 有专门的 Cookie 下载入口，本项目暂不使用。

### 3.2 项目约定（由本项目选择，并非供应商参数）

在项目根目录的 `.env.local` 保存：

```dotenv
FUYAO_BASE_URL=https://fuyao.aicubes.cn
FUYAO_API_KEY=
```

用户在步骤 7.4 亲自填写 `FUYAO_API_KEY`。`.env.example` 保留空值；`.env.local` 必须被 Git 忽略。Key 只由服务端或本地验证脚本读取，不放入前端，不使用 `NEXT_PUBLIC_` 前缀，不写入 URL、日志或 GPT 提示词。

本地独立 Node/TypeScript 脚本须显式加载 `.env.local`，不能假定它具有 Next.js 应用启动时的自动加载行为。

附件对关闭弹窗后能否再次查看完整 Key 的说法存在差异：AI 快速接入章节说只展示一次，快速开始章节说可在列表查看。以实际管理页面为准；创建后立即安全保存，不依赖再次展示。

## 5. 最小验证接口：A 股历史日线

### 5.1 方法与路径

```http
GET https://fuyao.aicubes.cn/api/a-share/prices/historical
X-api-key: <由服务端环境变量注入>
```

### 5.2 请求参数

| 参数 | 类型 | 必填 | 文档约定 | 本项目初次选择 |
|---|---|---|---|---|
| `thscode` | string | 是 | 完整标识，如 `600519.SH`；每次一个，不接受逗号 | `600519.SH` |
| `interval` | string | 是 | 当前端点仅支持 `1d`；参数表同时列默认 `1d` | 显式传 `1d` |
| `start` | long | 是 | 毫秒级 Unix 时间戳 | `1788192000000` |
| `end` | long | 是 | 毫秒级 Unix 时间戳，查询窗口跨度不超过 10 年 | `1790351999999` |
| `adjust` | string | 否 | `none`、`forward`、`backward`；默认 `forward` | 显式传 `none` |

测试区间为 `2026-09-01T00:00:00+08:00` 至 `2026-09-25T23:59:59.999+08:00`。它是本项目选择的短测试区间，不是已调用得到的数据范围。首次验证后按实际返回检查日期、边界与记录数量。

请求 URL（不含任何 Key）：

```text
https://fuyao.aicubes.cn/api/a-share/prices/historical?thscode=600519.SH&interval=1d&start=1788192000000&end=1790351999999&adjust=none
```

注意：

- 文档总览泛称日／周／月能力，但历史端点和对应 MCP 参数表明确“当前仅支持 1d”。本项目按具体端点执行，不实现 `1w`、`1m` 或分时参数。
- 默认前复权，所以必须显式传 `adjust=none`；遗漏参数会改变价格口径。
- “窗口跨度不超过 10 年”是参数限制，不能据此保证每只股票都有完整 10 年数据。
- 本项目先验证 `start <= end`，但不额外猜测端点分页参数、记录条数上限或精确端点包含语义。
- 单只股票接口使用单数 `thscode`；快照接口才使用复数 `thscodes`。

### 5.3 返回格式与字段

REST 返回统一信封，历史业务数据位于 `data.item`，不是响应根目录的 `item`。

```json
{
  "code": 0,
  "message": "success",
  "request_id": "文档示例的追踪ID",
  "data": {
    "timestamp": 1747584000000,
    "item": [
      {
        "date_ms": 1716134400000,
        "open_price": 1611.602,
        "high_price": 1626.602,
        "low_price": 1601.722,
        "close_price": 1602.612,
        "volume": 3142572.0,
        "turnover": 5401389334.87
      }
    ]
  }
}
```

上面数值摘自附件的历史响应示例，仅说明结构；它对应附件中前复权请求示例，**不是本项目 `adjust=none` 测试结果**。不要将其导入实际响应日志或据此确定未复权价格。

| JSON 字段路径 | 文档含义 | 单位／注意 |
|---|---|---|
| `code` | 业务结果码 | `0` 才是业务成功 |
| `message` | 结果描述 | 保留原始文本 |
| `request_id` | 请求追踪 ID | 保存以便定位问题 |
| `data.timestamp` | 序列中最新一根 K 线的上游有效时间／数据就绪时间 | 毫秒；不是每根 K 线的首次公开时间 |
| `data.item[i].date_ms` | K 线日期 | 毫秒；用 Asia/Shanghai 解释；不直接当作收盘发布时间 |
| `data.item[i].open_price` | 开盘价 | 股票价格按 CNY，元/股 |
| `data.item[i].high_price` | 最高价 | 同上 |
| `data.item[i].low_price` | 最低价 | 同上 |
| `data.item[i].close_price` | 收盘价 | 同上 |
| `data.item[i].volume` | 成交量 | 股，不是手 |
| `data.item[i].turnover` | 成交额 | 原始货币，A 股为 CNY |

价格具体响应示例未逐条返回 `currency`、`thscode`、`interval` 或 `adjust`。适配器需要保存请求中的标的、周期、复权参数；币种 CNY 来源于模块文档约定，不能声称这些元字段全由历史响应提供。

保留供应商返回的小数精度，不先把历史行情全部四舍五入为两位小数。真实成交价格和费用仍来源于用户交易记录，不能用每日行情替代真实成交。

## 6. 可选接口契约摘要

### 6.1 标的检索

`GET /api/meta/tickers/search`；同样使用 `X-api-key`。

| 参数 | 约定 |
|---|---|
| `q` | 必填，完整标识、纯代码或名称，支持子串匹配 |
| `asset_type` | 本项目传 `a-share`；指数解析传 `a-share-index` |
| `exchange` | 可选过滤，值按接口文档，不凭标识后缀推断所有参数值 |
| `limit` | 默认 10，最大 50 |

示例：`/api/meta/tickers/search?q=600519.SH&asset_type=a-share&limit=10`。

响应记录可含 `thscode`、`ticker`、`name`、`exchange`、`asset_type`、`currency`、`list_date` 等。由于 `q` 是子串搜索，需要再确认目标 `thscode` 和类型；不能取任意首条代替用户所选证券。保存代码为字符串，保留前导零。

### 6.2 指数历史日线

`GET /api/a-share-index/prices/historical`。

必填 `thscode`、`interval=1d`、`start`、`end`；一次一个指数，支持近 5 年数据，`end` 不早于 `start`。**不传 `adjust`，不传 `offset`**。例如上证综指 `000001.SH`，需和股票 `000001.SZ` 区分。

字段结构同历史 K 线；指数响应 `data.adjust` 固定为 `null`。指数数值按指数点展示，不把指数点称为元/股；股票与指数收益比较注明端点口径，不称为市场因果贡献。

### 6.3 交易日历

`GET /api/a-share/calendar/trading-days`，**无业务参数**。

固定返回 `[今日-1年, 今日]` 的交易日窗口，按 Asia/Shanghai 自然日；记录含 `date_ms` 与 `date`（`yyyyMMdd`），按时间升序。不能给它添加想象的历史起止参数，也不能用它覆盖窗口以外的交易日历。

原项目的 2025 年 3 月构造案例，在当前日期已经超出该近一年窗口；它仍可用于构造测试，但不能要求本接口给出该时段的完整日历。日历窗口不足时，单独标记验证能力受限。

### 6.4 除权除息事件

`GET /api/a-share/corporate-actions/adjustment-factors`。

| 参数 | 约定 |
|---|---|
| `thscode` | 必填，单个完整股票标识，不接受逗号 |
| `from` | 可选，`YYYY-MM-DD`，不是毫秒 |
| `to` | 可选，`YYYY-MM-DD`，不是毫秒 |

响应 `data` 包含标的和 `item`；事件按 `ex_date_ms` 降序。事件字段包括 `ticker`、`ex_date_ms`（上海时区除权除息日零点毫秒戳）、`dividend_per_share`（税前每股现金分红）、`per_share_bonus`（每股送股比例）。

**不返回** `event_type`、`record_date`、`adjust_factor`。不要让 Codex访问这些不存在的字段。附件不能据此确定完整配股细节或公告首次发布时间；除权日不等于公告公开日。

本项目用此能力检测收益口径可能受影响，暂不实现完整公司行动调整。接口失败或覆盖不明时，不把“未检出”写成“确认不存在”。

### 6.5 当前行情快照

`GET /api/a-share/prices/snapshot`，多标的用 `thscodes`；省略时才按 `limit`、`offset` 分页。返回 `last_price`、开高低、前收盘、量额等；不直接返回名称，需要元信息检索。

`price_change_ratio_pct=1.74` 表示 1.74%，不是比例 1.74。快照 `data.timestamp` 表示本次快照最新的上游有效时间，不代表每个标的都在同一时刻更新。当前快照不能当作过去某笔交易当时所见价格。

## 7. 资讯、资金和分时能力限制

附件“资讯事件库”章节明确：

- 能力暂未开放外部接入，当前接口说明是同花顺 AI 客户端内契约。
- `/api/news/events/search` 的示例也注明当前不可用于外部调用。
- 该内部端点的每秒 5 次说明，不能当作所有公开行情接口的统一 QPS。
- 事件主体、关联个股、新闻来源等字段透传不开放；其“标准时间”不能自动认定为首次发布时间。

因此，Codex不得为本网站直接实现此新闻调用，不通过浏览器 Cookie或客户端身份绕过限制。附件中的主力资金、高频动向也有客户端内能力说明，暂不纳入端外 Web MVP。

事件主链路采用用户录入或获准使用的材料：标题、原文摘录、原始链接、首次公开时间、时间精度、是否后来更新、来源类型。拿不出原始来源或时间时，标缺失/未知；不要用模型编写新闻填空。自动新闻接入需要另外取得明确允许外部接入的文档或提供方授权。

## 8. HTTP、业务错误与限流

### 8.1 判定顺序

1. 捕获连接失败、超时、TLS或非 JSON 响应，归为调用失败。
2. 检查 HTTP 状态；HTTP 429 无论响应体是否标准 JSON，都按限流处理。
3. 对成功 HTTP 响应继续检查 `code`；HTTP 200 但 `code!=0` 仍是业务失败。
4. `code=0` 后检查 `data`、`item`和必需字段，不把空数组伪装成正常有数据。
5. 保存实际 HTTP 状态、业务 code/message、request_id；脱敏，不保存请求头秘密。

附件个别模块写“HTTP 恒为200”，通用约定明确可能返回429。本项目按“同时检查 HTTP 和 code”实现，不假设永远200。

### 8.2 错误表

| 业务 code | 含义 | 本项目处理 |
|---|---|---|
| `0` | 成功 | 继续检查实际数据 |
| `1001` | 缺少必填参数 | 修复请求，停止无意义重试 |
| `1002` | 参数格式错误 | 检查标的、日期和时间戳单位 |
| `1003` | 参数越界 | 检查枚举、窗口和 limit |
| `1004` | 参数冲突 | 按实际端点约定修正 |
| `2001` | 未认证 | 检查Key配置，不打印值 |
| `2003` | 权限不足 | 记录 capability 未授权，不自动循环申请或重试 |
| `3001` | 标的不存在 | 核对标的解析结果 |
| `3002` | 数据未就绪 | 明确缺失/未就绪 |
| `3004` | 标的类型不支持 | 停止该能力调用 |
| `4001` | 限流 | 延后、降低频率；不能立即连续请求 |
| `5001` | 内部错误 | 明确失败，有限重试 |
| `5002` | 上游超时 | 明确失败，有限重试 |
| `5003` | 数据源不可用 | 明确失败，保留已有输入 |

### 8.3 频率与费用

附件说明当前不限制累计调用次数，但可依据负载动态限流。未提供公开历史行情的固定 QPS 或明确费用表；不据此宣称免费、无限并发、无限请求体或永久可用。

本项目初次验证采用串行调用。超时和重试上限由项目显式设置并记录，不伪装成供应商规定；鉴权/参数错误不重试，临时失败最多有限重试，不开高并发循环。

## 9. 时间、口径与证据映射

以下是本项目规则，不是接口额外保证：

| 项目字段 | 来源 |
|---|---|
| `source_kind` | 真实调用为 `provider_api`；构造为 `synthetic`；手动材料为 `user_provided` |
| `source_reference` | 实际供应商名、端点和 request_id |
| `symbol` | 实际请求 `thscode`，必要时检索确认 |
| `field_path` | 如 `data.item[0].close_price` |
| `bar_date` | 从 `date_ms` 按 Asia/Shanghai 解释，保留原毫秒值 |
| `price_basis` | 请求显式 `adjust=none`；不得用文档默认值覆盖实际参数 |
| `unit` | 文档约定：股票价格CNY元/股、volume股、turnover元 |
| `provider_data_timestamp` | `data.timestamp`，按该端点的真实语义标注 |
| `retrieved_at` | 本项目实际收到响应的时间，不覆盖供应商时间 |
| `published_at/available_at` | 接口未提供逐条可靠首次公开时间时保留未知，不能捏造 |
| `evidence_id` | 项目生成，绑定标的、端点、原字段、请求口径与版本 |

必须遵守：

1. `date_ms` 是日期标签，不等于当日收盘公开时间。完整当日日线不得进入上午交易的阶段A证据。
2. `data.timestamp` 是全序列最新数据有效时间，不是每根 K 线、每条新闻的发布日期。
3. 当前下载的历史数据不保证是当时的未修订版本；当时可得与用户当时实际看过也要区分。
