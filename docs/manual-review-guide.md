# 手动辅助A/B复盘操作指南

适用当前原项目：`D:\AI PM\Projects\investment-review`。在项目目录运行`npm.cmd run dev`，打开终端实际地址（通常http://localhost:3000）。本页没有模型API，不会请求收费接口；用户自行选择外部模型，复制前可以查看将交出的内容。不要把Key、完整账户或私人材料放进任务。

## 1. 导入与确认

1. 在“01 导入交易与构造案例”点击“一键载入构造案例”，或按既有CSV入口预览并确认整批导入。替换会覆盖当前字段数据，请先下载所需备份。
2. 到“03 AI复盘 · 手动辅助A/B”，等待按钮可操作。用“复盘决策交易”选要评估的交易。此选择是辅助链路的绑定；时间线的“选中决策交易”是另一个展示筛选，不替代这里的选择。
3. 勾选四项实际确认：
   - “我确认首次买入前无该证券持仓”；
   - “我确认本段交易没有遗漏”；
   - “我确认本段没有影响股数或现金流的公司行动”；
   - “我确认所选事件和行情属于当前持仓过程；理由按关联交易归属”。
4. 在同一位置逐条选择归属本过程的事件/行情。没选的资料不会进入A/B；可以保留缺失，不会自动生成。理由按关联trade_id归属。同证券有多个过程时须自行确认事件/行情属于哪段，不能仅因证券相同就全部勾选。

构造演示验收：载入内置案例，选`demo001-buy`（2025-03-03T10:00:00+08:00、BUY），在纯构造场景确认四项，并选中三事件、两日线共五项。预期A只有事前事件、前日构造日线、当时理由三条；B有九条记录快照及五条程序指标快照。2025-03-02周日日线是构造素材，不当作真实A股交易日。

这些勾选是持久化的用户声明，不是独立核验。顺序不明确、持仓为负、未清仓、未完成四项确认时不能生成正式任务；公司行动未知或存在时不要勾选“没有”，记录和现金展示仍可使用。金额保持“按录入交易暂算”，不会因为勾选而变成完整真实收益。

## 2. A：过滤、查看、复制、粘贴、校验与冻结

1. 点击“生成A任务”。程序按本次决策时点过滤，生成并保存独立包ID、过程ID、正整数修订号、SHA-256和不可变快照。
2. 查看“完整A任务预览”。只包含固定A规则、完整可达A_output JSON Schema和完整A_input。没有B正文/Schema、之后交易、最终盈亏、事后与时间未知原文，也没有完整Dataset、附件或隐藏全量时间线。当前交易只传ID、证券、方向和截止边界，不传它的成交价、数量、手续费。
3. 点击“复制完整A任务”。若剪贴板失败，页面明确报错，使用预览全选复制或“下载A任务TXT”。复制成功只代表复制，不代表模型已运行或复盘成功。
4. 在外部工具开启**独立干净上下文**，只粘贴完整A任务。不要附B任务、B结果、完整契约、ai-input-summary全文或完整构造案例。让外部工具仅返回一个纯JSON对象。
5. 回到页面，把返回文本放入“粘贴A结果JSON”。点击“校验并冻结A”。
6. 通过全部检查且本地写入成功后才显示“A已冻结”和来源说明。已冻结的A不能直接覆盖；要换A，请重新“生成A任务”，再导入新的完整JSON。旧B随新A失效。

输出中的七个元字段必须原样回传当前任务里的schema_version、stage、package_id、episode_id、episode_revision、input_hash、decision_trade_id，不手写哈希、不抄旧包。A的引用ID仅来自A快照，field_path相对该快照values，例如事件`/excerpt`、理由`/judgment`；不能写`/values/excerpt`。不在自由文本重复金额、价格、数量、费用、收益率；用引用展示原字段。

无事前证据仍可作受限A：必须明确missing_information和不能判断的原因，观察/假设数组保持空，不补造证据。prior只表示时间上可能可得，不代表用户看过或内容verified。

## 3. B：依赖有效A，复制任务与导入报告

1. A有效并冻结后，“生成B任务”才可用。点击它，程序把原冻结A及其原快照放入B，同时加入本过程执行记录、所选后续证据、回忆、未知状态、逐交易可见性和程序指标。B有自己的新包ID/哈希，不复用A值。
2. 查看“完整B任务预览”，点击“复制完整B任务”或“下载B任务TXT”。其内容为固定B规则、完整可达B_output Schema、完整B_input。冻结A已在B_input内，不需要手动重写或附整个Dataset。
3. 将完整B任务交给外部工具，返回一个纯JSON对象。在页面“粘贴B结果JSON”粘贴，再点击“校验B并形成报告候选”。
4. 全部校验和保存成功后出现“当前B复盘报告”。报告显示“构造演示报告”或“用户记录复盘（未独立核验）”，人工核验状态为待核验，不能当成已证实解释。
5. 每条结果可点“查看引用证据：…”查看冻结字段、来源、构造/质量标签、公开精度、可得时间、取数时间、原文和限制。下载“下载当前报告与快照”可以保留完整原包及导入JSON。

程序指标卡由代码固定：内置两笔案例买入1000.00元、卖出900.00元、费用10.00元、费用前-100.00元、净-110.00元，均来自录入交易，**不是行情接口提供**。缺费时total_fees/net_pnl为null/unknown，仅显示已知费用小计；不会把未知当零。模型输出没有指标回写字段，不能用文本、额外net_pnl字段或“新指标ID”覆盖它们。

B新结论只能引用B evidence，不能把A证据ID放进B引用。prior_basis须在该条目的decision_trade_id对应可见性中确为prior；后续事件不能证明买入时已知。回忆只能recollection/limitation，unknown只能limitation；冲突排除证据不得作为支持。解释和行为假设要有引用、待确认措辞及具体替代解释，没有证据允许空数组。

## 4. 学习清单候选

有效B后，在“04 学习清单与下一次决策”点击“选择当前报告候选”，关联当前B有效finding_id。不自动采用或保存条目，无条目不补造。

支持选择、编辑、勾选、删除、明确保存模板、导出/导入以及下一次决策理由/反证条件/检查记录。编辑不回写冻结B或改变证据修订号；旧决策保留不可变模板快照。实际按钮与错误处理见[清单操作指南](manual-learning-guide.md)。未保存编辑仍仅内存；报告认可/不认可核验按钮尚未实现，没有云同步。

## 5. 错误、失效与旧报告

- 非法JSON、围栏、重复键、额外字段、超过512KiB、字段/枚举/长度错误、元字段不符、不存在ID、空值路径或跨阶段引用：在“复盘校验错误”显示路径与原因，不自动修字段、不显示假成功、不覆盖已有合法结果。
- 本地保存失败：不会显示A已冻结/B已保存，不启用依赖未保存A的B。原始交易/证据保存失败时整个辅助链路也阻塞；先处理保存失败或下载备份。
- 修改交易、费用、成交/决策时间、理由内容、事件、行情采用或确认条件：保守递增相关保存过程修订，原任务/结果失效，需重新确认并重新A→B。当前没有直接编辑成交时间的表单，通过修正CSV并确认整批替换修改；旧过程不能绑定到新导入数据。
- “复盘决策交易”切换不增加证据修订，但当前任务/导入只绑定新选择；其他交易报告不冒充当前报告。修改理由版本的内容会失效；仅切换既有理由展示选择不篡改证据。
- 数据变化后旧记录保留，使用“查看过期报告（仅历史快照）”和“下载旧报告原快照”，不要将旧ID/哈希复制给当前任务。整批替换的旧过程不在新过程卡内显示，仍保留在本地辅助链路存储，不支持通用历史恢复。
- 本地存储读写冲突、损坏或限额阻塞时不覆盖旧内容；另一标签页变更后先刷新。辅助链路使用独立存储键investment-review:manual-review:v1，原字段存储不变。最多100个过程，每过程40包/40结果，总8MiB；超限明确拒绝，不删除旧快照。

真实行情始终unavailable，既有两次网络失败没有确认权限不足。该链路不请求供应商，不改变真实响应记录、不制造Key故障，不用构造结果当供应商返回值。

## 6. 实际验证与人工边界

自动化只用标明构造的测试输出，不在生产页面提供“一键成功报告”。新业务测试为`npm.cmd run test:review`；浏览器验证覆盖复制内容、A/B绑定、冻结/恢复、非法引用和金额覆盖拒绝、数据编辑失效、保存失败。实际最终命令与数量见STATUS最新阶段记录。

结构/引用/时间/金额和明显内容规则由程序检查；自然语言的引用支持程度、隐晦金融数字、伪装建议、因果与心理推断无法被规则完整证明，需要用户核对原证据和文本。历史版本、资料许可、来源真实性仍未独立验证；这不是语义审计通过。未执行真实模型/API或生产部署验收，未假称独立人工验收已完成。
