## 规格差异与边界

本阶段用户明确指定两笔交易和每笔费用5元，优先于 SPEC 原第14节四笔交易/费用案例；保留 SPEC 原文，后续验收不能继续套用原四笔案例预期。买入前日2025-03-02是周日；按用户指令保留为纯构造日线，不能解释为真实A股交易日。synthetic是来源类型，data_mode保留SPEC的constructed枚举。

当前提供导入、理由新增和统一证据查看，没有持仓识别、盈亏计算、事前/事后/未知分类、行情图、证据包、AI JSON校验、报告或学习清单。CSV只导入用户提供的交易，不补造其他三类记录。既有理由/事件自由编辑、通用JSON恢复与坏数据原文导出界面仍未实现。阶段schema尚不是SPEC的完整Episode/报告/备份根协议，后续需要明确迁移，不能静默覆盖已有格式。
