项目用于整理交易、理由与事件证据，按决策时点过滤信息，计算录入交易的现金暂算值，并通过手动辅助A/B流程形成待核验报告、学习清单和下一次决策记录。没有自动买卖或买卖建议，真实行情仍为 `unavailable`。

## CSV格式与构造样例

采用UTF-8，可带BOM。九个字段全部必须存在，不能增加未知或重复表头；模板顺序如下：

```csv
symbol,name,trade_date,trade_time,side,quantity,price,fee,same_day_order
DEMO001,构造示例公司,2025-03-03,10:00:00,BUY,100,10,5,1
DEMO001,构造示例公司,2025-03-10,14:00:00,SELL,100,9,5,1
```

| 字段 | 当前口径 |
| --- | --- |
| symbol / name | 证券标识/名称；构造CSV入口仅接受DEMO001，真实交易入口拒绝DEMO001 |
| trade_date / trade_time | 日期YYYY-MM-DD；时间HH:mm:ss，可空，按Asia/Shanghai解释；空时间不补00:00 |
| side | BUY或SELL，不是投资建议；导入时转换为大写 |
| quantity | 正整数，单位股；负数、零或非整数拒绝 |
| price | 正十进制价格，单位元/股，最多6位小数，不使用指数格式 |
| fee | 实际总费用，单位元；可为0或空，最多6位小数；空表示未知，不能默认0 |
| same_day_order | 正整数或空；同股票同日不能重复，不能与明确时刻矛盾；顺序不明需用户确认 |

CSV上限2MiB、5000条。错误定位至行/字段；疑似重复需明确保留或排除。先卖后买、卖出超过持仓拒绝整批采用，不用未来买入抵消错误。正常CSV仅导入交易，不自动生成理由、事件或行情。

保持现有文件名：

- [trades-template.csv](public/samples/trades-template.csv)：空模板。
- [demo-trades.csv](public/samples/demo-trades.csv)：上面两笔固定构造交易。
- [negative-quantity.csv](public/samples/negative-quantity.csv)：负数量错误。
- [missing-fee.csv](public/samples/missing-fee.csv)：买入费用缺失。
- [demo-case.json](public/samples/demo-case.json)：完整固定案例，含两笔交易、两份理由、三条事件、两条构造日线；不是通用JSON恢复入口。
- [acceptance-fixtures](docs/acceptance-fixtures/)：独立人工验收CSV/TXT，买入3月10日、卖出3月12日，与内置3月3日案例不同。

全部DEMO001素材是构造演示，不对应真实公司、新闻或交易。内置3月2日日线为周日构造素材，不能解释为真实A股交易日。`npm.cmd run fixtures:demo` 可按固定规则重建内置案例，不随机生成内容。

## 页面操作顺序

所有当前入口位于首页四区，并非已实现独立清单/设置路由。

1. **导入区**：点击“一键载入构造案例”，或选择“真实交易（用户提供，未验证）”/“构造 CSV（仅用于演示）”后“上传 CSV”。检查预览、重复及顺序，点击“确认整批导入”或“确认整批导入并替换当前数据”。替换前下载所需备份；当前不合并历史持仓。
2. **补理由和事件**：理由表单选择关联交易，填写核心判断、原摘录、来源及已知形成时间，点击“保存新增理由”。新增不覆盖旧版本。内置“当时记录 / 事后回忆”切换只是展示选择，不伪造旧原文。
3. **时间线区**：选择决策交易和分类范围，点击“查看来源详情”，核对原字段、单位、公开/可得/取数时间、质量和构造标签。“全部记录”查看持仓与现金暂算；事前视图不显示全程盈亏。
4. **AI复盘区**：按下面A/B步骤生成任务、手动导入JSON。没有有效结果时保持未生成，不提供“一键成功报告”。
5. **清单区**：点击“选择当前报告候选”，编辑问题/依据/材料及适用范围，勾选“采用检查项”和“已人工检查”，可增删或上移，点击“确认保存清单”。用户自建无来源条目明确提示缺来源，不补造证据。
6. **下一次记录**：保存清单后点击“开始下一次决策记录”，只填写决策理由、反证条件、检查状态/说明和用户证据文本或链接。可保存草稿、完成或退回草稿；不生成买卖/仓位建议。模板以后编辑或删除不会改变已创建记录的快照。
7. **备份**：可下载当前字段数据、报告及快照；清单提供“导出清单与决策备份”和经校验、预览、确认后的导入。清单备份整体替换清单/决策，不替换交易或A/B存储。

详细按钮、填写值与预期结果见[人工材料说明](docs/manual-acceptance-11.md)、[辅助复盘指南](docs/manual-review-guide.md)、[清单操作指南](docs/manual-learning-guide.md)。

## TXT或粘贴事件

“用户上传事件证据”支持“上传证据原文（TXT）”或直接填写“事件原始摘录（必填）”。只接受UTF-8 .txt，最大64KiB，摘录1–2000字符；不能可靠解码或超限时拒绝，不截断。

填写关联证券、事件标题、来源名称，可选http/https链接；选择“首次发布时间精度”（未知、仅日期、日期与时刻），按已知情况填写原始首次公开日期/上海时刻。未知不补时刻。确认摘录对应当时历史版本后，点击“保存新增事件证据”。勾选历史版本是用户声明，不是独立档案核验；当前修改后的旧报道没有旧版本不能作为原始事前内容。

不会访问链接、抓取网页或调用模型。用户CSV、理由和事件均保留 `user_provided / unverified`；构造入口另保留 `is_constructed:true`。内置固定素材的 `source_type:synthetic` 保持不变。上传资料不是供应商数据，录入时间不作发布时间，`fetched_at` 保持null。

## 辅助A/B与模式差异

| 模式/用途 | 实际状态 |
| --- | --- |
| 缓存查看 | 刷新恢复已保存数据/任务/冻结结果，不重新调用模型；旧报告保留原快照，过期不能当当前有效结果。没有内置预生成成功A/B缓存报告；测试输出不进入生产页面 |
| 人工辅助A/B | 已实现：程序过滤输入、生成完整规则/Schema/任务，用户交给外部工具，粘贴JSON校验后保存；无需模型Key |
| 站内自动API | 未实现，没有模型配置表单、自动生成或自动模式开关；聊天订阅/开发工具权限不等于独立API权限 |

实际A/B顺序：

1. 在“复盘决策交易”选择交易（与时间线展示选择独立），确认零期初持仓、无遗漏、无影响股数/现金流的公司行动和证据归属；显式选择所属事件/行情。未清仓或确认不足不能生成正式任务，缺费/缺行情可以保留限制。
2. 点击“生成A任务”，查看“完整A任务预览”，用“复制完整A任务”或“下载A任务TXT”。A只含事前允许证据与当前决策标识/截止边界；不含未来交易、最终盈亏、事后/未知/回忆原文或隐藏全量Dataset。
3. 在外部模型的独立干净上下文只粘贴A任务。将一个纯JSON对象放入“粘贴A结果JSON”，点击“校验并冻结A”；无事前证据时允许受限判断，不编造支持。
4. A有效冻结后点击“生成B任务”，查看/复制完整B任务；其中绑定原A及快照、本过程执行记录、后续/回忆/未知状态和程序指标。外部JSON粘入“粘贴B结果JSON”，点击“校验B并形成报告候选”。
5. 展开引用核对原文、ID、版本及质量。非法JSON、重复键、额外字段、错绑定/哈希、不存在ID、非法路径、越阶段引用或模型金额覆盖明确拒绝，不自动修复、不覆盖合法旧结果。资料修改使相关结果过期，重新A→B；结果内容仍需人工核验。

模型不参与时间过滤、持仓识别或金额计算。完整任务含相关用户文本，复制前自行查看；不要交出Key或无关账户材料。复制成功不表示模型已运行，保存成功不等于语义/因果/心理解释已证实。无收费模型API由本项目自动调用；外部工具的使用条件由用户自行选择。

## 时间与现金口径

时间以Asia/Shanghai解释，保留证据ID、来源字段、单位、时区、精度、首次可得与取数时间。按**首次可得时间及历史版本**决定事前/事后/未知；不以发生日、录入时间、created_at或fetched_at替代。可得时刻等于截止边界不判事前，同日仅日期信息未知；盘中交易不能知道当日完整收盘日线。prior仅表示时间上可能可得，不表示当时实际阅读或资料verified。

交易按证券、日期/时刻和已确认顺序识别，从零持仓到回到零持仓为闭合过程；未回零标open，不强行清仓。负持仓或顺序不明阻止正式采用/计算。

- 买入额B、卖出额S均不含费用；费用前盈亏=S−B。
- 费用全部已知时，现金净盈亏=S−B−全部实际费用；任一费用未知，total_fees/net_pnl为null，仅显示已知费用小计和费用前盈亏。
- 十进制采用BigInt定点整数处理，保留输入不足一分精度至汇总/差额后，四舍五入为整数分，展示两位小数；不是浮点金额运算。
- 未清仓不展示完整盈亏，不按市价估计未卖出部分。分红、拆股、送股、配股等复杂行动限制简化计算，明确存在时阻止；时间线公司行动选择为临时展示选择，A/B另有持久化用户确认，均未独立核验。
- 内置两笔案例：买入1000.00元、卖出900.00元、费10.00元、费用前−100.00元、净−110.00元。仅依据录入交易**暂算**，不是行情接口收益或完整投资回报。
- 当前没有收益率、年化、基准超额或完整公司行动调整指标。首次买入下内置9条证据为事前3/事后5/未知1；仅导入交易CSV不会得到这些完整证据。
